# Student_Record_Management_System
A C-based Student Record Management System using a Singly Linked List. It allows users to add, view, modify, and delete student records. The system supports sorting and reversing student records. Student data can also be saved to a text file using file handling.
# Student Record Management System

A simple **Student Record Management System using C** and a **Singly Linked List**.

## Features

* Add new student record
* Display all records
* Modify student details
* Delete a record
* Delete all records
* Sort records by name
* Reverse the list
* Save records to a file
* Auto-generate roll numbers

## Student Details

Each record contains:

* Roll Number
* Name
* Percentage

## Technologies

* **Language:** C
* **Data Structure:** Singly Linked List
* **File Handling:** `student.txt`

## Menu

```text
A - Add Record
S - Show Records
M - Modify Record
D - Delete Record
L - Delete All Records
T - Sort Records
R - Reverse List
V - Save Records
E - Exit
```

## Concepts Used

* Structures

* File Handling
